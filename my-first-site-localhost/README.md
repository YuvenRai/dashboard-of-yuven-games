# dj_click_deck

## Run locally

Open `index.html` with a local web server, or run `Start-DJ-Click-Deck.cmd`
and open <http://127.0.0.1:8765/>.

Create a username and Game Code, then use them to load that game in the same
browser at the same site address. To send progress to another browser or
device, select **Email or share save** while playing and choose an email app
from your device's share menu. If file sharing is not available, use
**Save file to this device** and attach the downloaded JSON file to an email
yourself.
On the other device, enter a username and Game Code and choose **Import save
file**. If that username already exists there, enter its Game Code to confirm
the import. The save file contains game progress, not the Game Code. Accounts
and scores are never sent to a DJ Click Deck server. Keep your Game Code
private; if you forget it, the local account cannot be recovered. Microphone
recordings are available only until the page is closed. Each inappropriate
username attempt adds 24 hours to the timeout for account creation,
loading, and save imports. During the timeout, use the sign-in panel's note
link to report a mistake.

Camera and microphone features require browser permission. The feedback page
downloads your note as `mistake-note-djclickdeck-feedback.pdf`; it does not
send it online.
